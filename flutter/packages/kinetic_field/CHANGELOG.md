## 0.2.0 - 2026-08-20

* Added versioned raw input frames with independent bilateral landmarks.
* Added shared One Euro filtering, short-horizon prediction, occlusion handling
  and bilateral motion events.
* Added distinct Bloom, Honeybees, Fireflies and Moon Pond scene strategies and
  renderers.
* Added one-pointer and two-pointer fallback input with direct response.
* Added depth and trail settings, processed motion state and adaptive Automatic
  quality while retaining the legacy `MotionSample` adapter.

## 0.0.1

* Added the platform-neutral motion sample and field settings model.
* Added the `ChangeNotifier` controller with external motion and pointer input.
* Added the responsive `CustomPainter` particle vortex and performance stats.
* Added focused controller, model and widget tests.
